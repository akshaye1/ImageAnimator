# **App Name**: TearDrop

## Core Features:

- Torn Edge Application: Apply a torn paper edge effect to a user-selected image. User should be able to control the size/amount of tearing.
- Shadow Effect: Add a customizable shadow effect to the torn edge to give a 3D appearance. User should be able to control direction, intensity and color of the shadow.
- Image Upload: Allow users to upload images from their local device.

## Style Guidelines:

- Neutral background colors (light grays or off-whites) to emphasize the image.
- Subtle accent color (e.g., a muted blue #77B5FE) for interactive elements.
- Clean and intuitive layout with clear visual hierarchy.
- Simple, outline-style icons for controls and actions.
- Subtle transitions and animations for a smooth user experience.

## Original User Request:
An app that applies a torn texture border to the image and adds a shadow to the border for a 3d effect.
